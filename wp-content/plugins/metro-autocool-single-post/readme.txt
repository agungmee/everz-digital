== Description ==
Plugin untuk menampilkan halaman single post blog dengan gaya yang sama seperti halaman utama Metro Autocool. Dilengkapi dengan navbar, footer, related posts, dan sticky WhatsApp button.

== Installation ==
1. Upload folder 'metro-autocool-single-post' ke /wp-content/plugins/
2. Activate plugin di WordPress Dashboard
3. Setiap post/artikel akan otomatis menampilkan template ini

== Features ==
- Responsive design (mobile, tablet, desktop)
- Navbar dan footer konsisten dengan halaman utama
- Featured image yang menarik
- Author info, publish date, dan reading time estimate
- Related posts section (3 post terbaru selain post saat ini)
- Sticky WhatsApp button dengan animasi bounce
- Font awesome icons
- Dark theme dengan accent color merah
- Meta tags (Open Graph, Twitter Card)

== Usage ==
Plugin ini bekerja secara otomatis. Setiap kali Anda membuat atau edit post, template single post akan diterapkan secara default.

Customization:
- Edit /assets/css/single-post.css untuk mengubah styling
- Edit /templates/single-post-template.php untuk mengubah layout
- Edit /includes/class-single-post-template.php untuk mengubah functionality
