# Metro Autocool Single Post Plugin

Plugin untuk menampilkan halaman single post blog dengan gaya yang sama seperti halaman utama Metro Autocool.

## 📁 Struktur File

```
metro-autocool-single-post/
├── metro-autocool-single-post.php          # Main plugin file
├── readme.txt                               # Plugin documentation
├── includes/
│   └── class-single-post-template.php      # Main plugin class
├── assets/
│   └── css/
│       └── single-post.css                 # Plugin styling
└── templates/
    └── single-post-template.php            # Single post template
```

## ✨ Fitur

- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Navbar dan footer konsisten dengan halaman utama
- ✅ Featured image yang menarik
- ✅ Author info, publish date, dan reading time estimate
- ✅ Related posts section (3 post terbaru)
- ✅ Sticky WhatsApp button dengan animasi bounce
- ✅ Dark theme dengan accent color merah (#dc2626)
- ✅ Font awesome icons
- ✅ Meta tags (Open Graph, Twitter Card)

## 🚀 Instalasi

1. Upload folder `metro-autocool-single-post` ke `/wp-content/plugins/`
2. Go to WordPress Dashboard → Plugins
3. Find "Metro Autocool Single Post" dan klik Activate
4. Done! Setiap post akan otomatis menggunakan template ini

## 🎨 Styling

Template menggunakan:
- **Font:** Barlow Condensed (bold & uppercase headings)
- **Color Scheme:**
  - Primary Red: #dc2626
  - Dark Background: #050505, #0a0a0a
  - Text: #ffffff, #e7e7e7
  - Borders: #1f1f1f, #2a2a2a

- **Responsive Breakpoints:**
  - Desktop: 1024px+
  - Tablet: 960px, 640px
  - Mobile: 480px

## 📝 Customization

### Mengubah Styling
Edit file `/assets/css/single-post.css`

### Mengubah Layout
Edit file `/templates/single-post-template.php`

### Mengubah Functionality
Edit file `/includes/class-single-post-template.php`
