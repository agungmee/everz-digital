🚀 HOW TO USE

1. EDIT EXISTING SECTION:
   ↓
   Open desired section file in sections/ folder
   Edit HTML content
   Save file
   Refresh browser → Changes live!

2. ADD NEW SECTION:
   ↓
   Create new HTML file in sections/
   Add entry to sections-loader.js
   Add placeholder div to index.html
   Refresh browser → New section loaded!

3. DEBUG:
   ↓
   Check browser console (F12)
   Verify fetch requests succeed
   Check if placeholder IDs match loader config
   Use browser DevTools to inspect loaded content
