## 🎯 Cara Kerja

1. **index.html** memuat semua CSS dan placeholder divs
2. Saat halaman dibuka, **sections-loader.js** otomatis:
   - Fetch setiap file dari folder sections/
   - Replace placeholder dengan HTML asli
   - Run semua JavaScript functionality

3. Halaman render sempurna seperti sebelumnya, tapi struktur lebih rapi

## 📝 Contoh Penggunaan

### ✏️ Untuk Edit About Section:
1. Buka: `sections/about.html`
2. Edit HTML content
3. Simpan file
4. Refresh halaman → Perubahan langsung terlihat

### ➕ Untuk Tambah Section Baru (misal: Pricing):
1. Buat file: `sections/pricing.html`
2. Write HTML content
3. Buka `sections-loader.js`, tambah ke array:
   ```javascript
   { id: 'pricing-placeholder', file: 'sections/pricing.html' }
   ```
4. Buka `index.html`, tambah placeholder:
   ```html
   <div id="pricing-placeholder"></div>
   ```
5. Done! Section akan auto-load

### 🔧 Untuk Edit JavaScript:
- Semua scripts ada di `initializeScripts()` function di `sections-loader.js`
- Edit sesuai kebutuhan
- Otomatis run setelah sections loaded
